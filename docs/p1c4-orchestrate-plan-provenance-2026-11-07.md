# P1-C4 — inspect actual orchestrate Plan, do not launder legacy OWNED into authority

Date: 2026-11-07. Base main `7b34f39fa560320c652e28a74851617613941fc1`. Tracks [Core MVP Issue #56](https://github.com/saymer-alt/vps-gateway-bootstrap/issues/56), after merged P1-C3 PR #77.

**Status: repository-only, read-only proof of a full Plan shape. NOT independently trusted ownership, executable broker or production admission.**

`internal/brokerplan.InspectPrepared` invokes the EXISTING `orchestrate.Prepare` lifecycle on a *caller-injected* discovery/config/executor fixture. It requires only the first pinned fail2ban.service repair intent, exactly one legacy OWNED declaration and service executor kind, no State or file inspector overrides, complete discovery and canonical present machine-id, READY full preflight and no constraints, exactly one service.UPDATE diff and typed restart action, and exactly the compiled Stage-4 capability `muvg.service.restart.v1;unit=fail2ban.service`. A custom capability derivation callback is discarded in favour of `apply.RequiredCapabilities`. The fingerprint comes from `orchestrate.Fingerprint(p.Plan)` on the complete prepared Plan, not an agent-supplied digest. Host identity comes from live-discovery machine-id fields, not hostname or config.

**Blocking truth:** the current pipeline uses legacy config/state `OWNED` labels. Config can self-assert OWNED but cannot independently prove resource provenance. The Stage-3 evidence/corroboration and plan-wide trusted admission are not wired to this broker. For that reason `Candidate.Snapshot().Ready` is **hardcoded false** even if the plan is structurally ready and even if an Ed25519 v2 approval correctly signs its exact fingerprint and host. The candidate is *for operator review only*. There is no production `ReadPlan` provider and no path that promotes it to an executable broker. Do not remove this fail-closed gate merely to get a green test; the next milestone must independently prove ownership with trusted journal/evidence/live discovery.

Negative tests: incomplete/UNKNOWN/PARTIAL discovery; absent/unreadable machine-id; missing/duplicate/active service; unsupported executor; failed root preflight; injected persisted state or file inspector; foreign/extra/missing legacy ownership labels; extra or foreign service, SSH/file/MUVG intent; missing config. Positive tests assert a true full orchestrate.Plan was prepared and its compiled capabilities and fingerprint match; a separately valid signed-v2 request remains refused by `brokergate` due uncorroborated ownership. No executor methods invoked.

**Not tested:** real trusted source provenance, independent Stage-3 ownership, verified journal, locks/staleness, rollback, operator off-box signing ceremony, OS-level agent/root isolation, systemd, SSH management and host production readiness. No live VPS, key, service, release or existing runtime path is changed. Legacy `--confirm` and Stage-5 whole-plan admission still remain open.
