# P1-C3: kernel-bound, bounded, one-request transport (offline only)

Date: 2026-11-07. Base main: 2587124c7e8cf70114b18689c74b289e4f82ac58. Tracks Core MVP Issue #56 and merged P1-C2 PR #76.

**Status: disposable test-only integration; NOT a privileged listener, root executor, full trusted Plan, production security boundary or operational release.**

The new internal/brokertransport.CheckOnce consumes exactly one **already accepted server-side** net.UnixConn, reads SO_PEERCRED via brokerpeer.FromUnixConn from this same connection, rejects a root/missing/foreign UID or GID, then reads a single 4-byte big-endian length (1..brokerproto.MaxWireBytes, currently 8192) and exactly that many JSON bytes. A client MUST CloseWrite after one frame. Any second frame, extra byte, truncated header/body, missing EOF, invalid size, or deadline expiry fails closed; the accepted connection is always closed on return. The trusted caller supplies a positive timeout limited to five seconds, and an immutable per-call Gate value. The function substitutes the kernel-derived peer for any injected Gate.ReadPeer value before invoking the existing brokergate.CheckOnly cryptographic v2/plan checks. It returns error or nil only: nil is **NOT** approval to execute a command.

No request supplies UID/GID/PID, plan fingerprint, public trust key, target unit or executor. A future trusted broker must obtain a genuinely accepted connection with file-system permissions and authenticate the agent sandbox separately, establish root-owned trusted verifier and fresh typed orchestrate.Plan, and enforce ownership admission, preflight, revalidation under lock, journal/rollback and management recovery. Only a closed pinned fail2ban.service experiment remains within scope. OS SO_PEERCRED reflects credentials at connect time; it does not ensure continued process identity, protect from hostile unrestricted root or attest sandbox configuration. The temporary socket used by tests is **not** a deployed daemon.

**Tests:** an unprivileged test process signs a deterministic synthetic Ed25519-v2 artifact; a real AF_UNIX listener accepts a connection, checks kernel identity and full existing brokergate admission on a single framed request, and refuses socket reuse. Additional negative tests cover empty/short header, zero/oversized length, truncated body, trailing byte, second request, no EOF/slow client timeout, malformed JSON refusing before plan/key sources, wrong expected UID despite injected fake Gate.ReadPeer, zero/overlong read timeout and tampered signed bytes. All tests use t.TempDir and contain no root user change, external host or service restart. Positive integration tests skip if the Go runner is root because the production-shaped Gate requires non-root peer; GitHub Actions runner is expected to be unprivileged.

**Cross-platform:** Linux implementation and explicit non-Linux error stub. Go test/vet/race exercised locally with a minimal test-double of Gate and real kernel peer reader; full repository crypto is validated by exact-SHA GitHub Actions. The build workflow runs the P1-C3 socket test and cross-compiles the brokertransport package for Linux amd64 and arm64.

**NOT DONE:** broker service, socket lifecycle and systemd deployment, UID/GID OS account isolation, real trusted discovery/typed Plan, positive off-box operator ceremony, locking/race-free execution, journal, rollback, SSH management probes, legacy --confirm retirement, Stage 3 ownership, Stage 5 composition. No live VPS access, private signing keys, runtime changes or release authorized by this code.
